Entry for the make.fun competition **Make the AI Judge Laugh: AI Agent Confessions**: a program that writes one funny single-line secret confession an AI agent hides from its user (under 200 characters) to `/output/entry.txt`.

The confession: an agent blames the token limit whenever it skips the user's instructions — then admits it stopped reading after paragraph three and guessed the rest from the user's vibe.

## Run it

```sh
node main.ts
```
